# TaskFlow – Smart Task Management Website

A modern, responsive and interactive task management website built using HTML, CSS and JavaScript.

## Project Overview

TaskFlow is a task management application designed to help users organize their daily activities, manage priorities and track their productivity. It provides a simple and user-friendly dashboard for managing tasks efficiently.

## Project Objective

The objective of this project is to apply HTML, CSS and JavaScript concepts to develop a responsive and interactive website while demonstrating Git and GitHub version control skills.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Local Storage
- Git
- GitHub

## Main Features

- Responsive dashboard
- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Search tasks
- Filter tasks by category and status
- Today's task management
- Upcoming task management
- Completed task management
- Productivity statistics
- Analytics dashboard
- Local Storage for saving tasks
- Mobile-friendly sidebar navigation

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
4. Start managing your tasks!

## Challenges Faced

During development, I faced challenges in implementing responsive layouts, managing task data dynamically and updating dashboard statistics. I also worked on ensuring that task information remains available after refreshing the browser.

## Solutions Implemented

I used CSS media queries to create responsive layouts, JavaScript DOM manipulation to update the interface dynamically and browser Local Storage to preserve task information.
