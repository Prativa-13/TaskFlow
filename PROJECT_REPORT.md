# TaskFlow – Final Web Development Project Report

## 1. Project Objective

The objective of TaskFlow is to develop a responsive and interactive task management website using HTML, CSS, and JavaScript. It helps users organize daily activities, manage tasks efficiently, and track their productivity through a simple dashboard.

## 2. Project Overview

TaskFlow is a web-based task management application with a clean dashboard and user-friendly interface. Users can create, edit, delete, search, filter, and complete tasks. The dashboard displays task statistics and progress information. The application uses browser Local Storage to save task information, allowing users to retain their tasks even after refreshing the page.

## 3. Technologies Used

- HTML5 for website structure and semantic elements.
- CSS3 for styling, Flexbox, Grid, and responsive layouts.
- JavaScript for application logic and interactive functionality.
- Local Storage for saving task data.
- Git and GitHub for version control.
- GitHub Pages for website deployment.

## 4. Main Features

TaskFlow includes a dashboard with task statistics, task creation and editing, task deletion, task completion, search functionality, category and status filtering, upcoming and completed task views, progress tracking, and a responsive mobile sidebar. The website supports desktop, tablet, and mobile devices.

## 5. Challenges Faced and Solutions Implemented

One challenge was creating a layout that works properly across different screen sizes. I solved this by using CSS Flexbox, Grid, and media queries. Another challenge was updating the interface whenever a task was added, edited, or deleted. I used JavaScript DOM manipulation and event handling to update the displayed information. Local Storage was implemented to preserve task data between browser sessions. I also learned how to initialize a Git repository, create commits, connect it to GitHub, and push project files.

## 6. Key Learnings

Through this project, I improved my understanding of HTML structure, CSS styling, responsive web design, JavaScript functions, arrays, objects, DOM manipulation, event handling, and browser storage. I also gained practical experience with Git commands, GitHub repositories, and website deployment.

## 7. Future Improvements

In the future, I would like to add user authentication, cloud-based data storage, reminders, task deadline notifications, and collaboration features so multiple users can manage tasks together.
